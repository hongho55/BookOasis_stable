# BookOasis Sans

`BookOasisSans-Variable.woff2`는 Pretendard Variable 1.3.9(Copyright (c) 2021 Kil Hyung-jin, SIL Open Font License 1.1)를
완성형 한글 2,350자 + 영문·기호로 잘라 만든 파일이다. OFL의 Reserved Font Name 조항에 따라 글꼴 이름을 'BookOasis Sans'로 바꿨다.
라이선스 전문: [OFL.txt](OFL.txt) · 생성 스크립트: `tools/fonts/build_app_font.py`
